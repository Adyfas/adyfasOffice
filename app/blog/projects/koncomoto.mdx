<Heading>Koncomoto Dashboard</Heading>

Koncomoto Dashboard is a web-based client management system designed to automate booking, invoicing, payment tracking, and event scheduling.  
This dashboard helps the business reduce manual administrative work by centralizing all client-related processes into a single, efficient system.

The platform automatically generates invoices when a client books a service, sends scheduled reminders via WhatsApp and email, and allows clients to complete payments directly through an integrated payment gateway. Once payment is confirmed, the system records the event date and synchronizes it with Google Calendar for better scheduling and tracking.

<Section />
<Heading>Problems</Heading>

Before this system was built, the company managed client bookings, invoices, reminders, and payment confirmations manually.  
This workflow caused several issues, including:
- Inefficient administrative processes
- Missed or delayed payment follow-ups
- Difficulty tracking client payment status
- Manual event scheduling that was prone to errors

As the business grew, these manual processes became increasingly difficult to manage and required a more automated and scalable solution.

<Section />
<Heading>Solution</Heading>

To address these challenges, I designed and developed Koncomoto Dashboard as an end-to-end automation system.  
The dashboard centralizes client data and automates key operational workflows, allowing the business to focus more on service delivery rather than administrative tasks.

The system ensures that invoices, reminders, payments, and scheduling are handled automatically and consistently, reducing human error and improving overall operational efficiency.

<Section />
<Heading>Key Features</Heading>

1. Client data management and booking system  
2. Automatic invoice generation  
3. Scheduled reminders via WhatsApp and email  
4. Online payment integration using Xendit  
5. Real-time payment status notification for admin  
6. Automatic event scheduling and synchronization with Google Calendar  

<Section />
<Heading>My Role</Heading>

I worked as a **Full Stack Developer** on this project and was responsible for the overall system architecture, development, and integration.

I built the main dashboard using **Next.js** as a full-stack framework, handling both frontend and backend logic.  
For messaging automation, I developed a custom **WhatsApp bot using Express.js**, enabling scheduled reminders and payment notifications.

The system integrates multiple third-party services, including**:**
1. **Xendit** for payment processing
2. **Google Calendar API** for event scheduling
3. **Email services** for automated invoice delivery and reminders
