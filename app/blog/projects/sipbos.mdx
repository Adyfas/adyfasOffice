  <ul>
    <li>
      <strong>Prisma</strong> — ORM modern untuk Node.js yang saya gunakan untuk{" "}
      <em>mapping</em> antara kode dan database. Prisma memudahkan penulisan query,

    <li>
      <strong>Express.js</strong> — Framework backend berbasis Node.js yang menjadi

      sebagainya dengan konsistensi tinggi.
    </li>
    <li>
      <strong>Bcryptjs</strong> — Library untuk <em>hashing</em> password sehingga

    </li>
    <li>
      <strong>Google-auth-library</strong> — Digunakan untuk integrasi dengan
      layanan Google, terutama dalam proses autentikasi atau verifikasi yang
      terkait akun Google.
    </li>
    <li>
      <strong>Jsonwebtoken (JWT)</strong> — Teknologi untuk membuat token
      autentikasi yang aman, sehingga user yang sudah login dapat mengakses API
      tertentu tanpa harus mengirim password terus-menerus.
    </li>
    <li>
      <strong>Multer</strong> — Middleware untuk menangani <em>file upload</em>,
      misalnya upload foto produk atau dokumen lain, dengan pengelolaan yang rapi
      dan terkontrol.
    </li>
    <li>
      <strong>Node-appwrite</strong> — SDK untuk berkomunikasi dengan layanan{" "}
      <Hyperlink link="https://appwrite.io">Appwrite</Hyperlink>, biasanya untuk

      backend lain.
    </li>
    <li>
      <strong>Passport</strong>, <strong>Passport-google-oauth20</strong>,{" "}
      <strong>Passport-oauth</strong> — Kumpulan library untuk mengelola{" "}
      <em>OAuth</em> dan <em>third-party login</em> (seperti login dengan Google),
